# Statistical Inference: Simulated Particle Physics Data Analysis

This repository contains a simplified particle physics analysis, demonstrating the process of statistical inference—drawing conclusions about a larger, unseen population from a limited sample of data. By generating and analysing thousands of simulated "events", this project infers the fundamental properties of a particle and verifies the robustness of the statistical methods used.

---

## Overview

In high-energy physics, robust data analysis is crucial for separating physical signals from background noise. This project walks through a complete inference pipeline:
* Generate binned simulated data from real-world parameters for a signal (a "particle") superimposed on a background.
* Fit a mathematical model to this observed data.
* Evaluate the "goodness-of-fit" and calculate the p-value of the underlying model.
* Perform a rigorous "pull study" across hundreds of toy experiments to check if the fitting procedure is unbiased.

---

## Mathematical Modelling

The total expected yield in each mass bin is modelled by combining both signal and background probability density functions (PDFs). 

* **Signal:** Modelled using a Gaussian distribution, defined by the true particle mass ($\mu = 125.0$) and particle width ($\sigma = 5.0$).
* **Background:** Modelled using a simple exponential decay function, driven by a background decay constant ($\tau = 30.0$).

The combined model is scaled by the respective number of signal events ($N_{sig} = 6500$) and background events ($N_{bkg} = 200000$).

---

## Methodology

### 1. Data Simulation
Expected event counts are calculated across a defined mass range. To accurately reflect a real counting experiment, the observed data is then generated by applying Poisson statistics to the expected yields. Data point uncertainties are calculated as the square root of the observed counts.

### 2. Model Fitting
The project utilises `scipy.optimize.curve_fit` to perform a $\chi^2$ fit on the binned data, extracting the best-fit parameters alongside their covariance matrix. The goodness-of-fit is quantified by computing the degrees of freedom and the corresponding p-value.

### 3. Bias Validation (Pull Study)
To ensure the fitting procedure is unbiased, a pull study is executed:
* 1000 toy experiments are generated by sampling parameter values from a multivariate normal distribution based on the fitted parameters and their covariance.
* Each toy experiment is fitted, and the "pull" for each parameter is calculated using the formula: $\frac{\text{Fitted Value} - \text{True Value}}{\text{Fitted Error}}$.
* A Gaussian is finally fitted to the binned pull distributions to determine their mean and width, providing a definitive evaluation of any fit bias.

## Dependencies

To run the analysis notebook, the following Python libraries are required:
* `numpy`
* `matplotlib.pyplot`
* `scipy.optimize` (specifically `curve_fit`)
* `scipy.stats` (specifically `chi2` and `multivariate_normal`)
